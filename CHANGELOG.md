# Change Log
All notable changes to the "sublime-duplicate" extension will be documented in this file.

## [1.0.0] - 2018-06-29
- Initial release

## [1.0.1] - 2018-06-29
- Added icon image

## 1.0.2 - 2025-04-06
- Transitional version
- Minor adaptations to newer npm and newer vscode  version

## 1.0.3 - 2025-04-06
- Added split functionality for copy and past; the original functionality was left untouched

## 1.0.4 - 2025-04-06
- Minor fixes of 1.0.3
- A LICENSE.MD file was added.

### 1.0.5
- When pasting over a selection, the selected text is now replaced with the copied content. If the copied content is a full line, it no longer inserts a line break when replacing a selection. - Unselected pastes behave as before.
